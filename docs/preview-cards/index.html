Laboratório conceitual: esta prévia utiliza dados locais demonstrativos. Não faz login, não modifica o banco, não distribui cartas e não implementa combate nem evolução. Equipamentos e movimentos são somente simulações locais. A arte é um símbolo provisório. As molduras cromadas são uma simulação CSS para avaliação visual, sem arquivos finais de arte. Raridade é apenas uma proposta de aparência, sem probabilidades, bônus ou regras de distribuição. Alterações de origem e bola simulam cartas diferentes; não representam mudanças permitidas em uma carta já criada. Movimentos e equipamentos são interações locais temporárias.
